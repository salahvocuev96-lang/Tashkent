# Сайт чайханы «Ташкент» — демо-версия

Одностраничный сайт: первый экран, меню с поиском и разделами, корзина, демо-оформление заказа, блок о чайхане, контакты.
Чистый HTML, CSS и JavaScript — без библиотек, сервера и сборки.

## Файлы

- `index.html` — разметка страницы.
- `style.css` — оформление и анимации.
- `script.js` — **данные меню (в самом начале файла)** и вся логика: поиск, разделы, корзина, оформление.
- `images/` — создайте эту папку и кладите в неё свои фото блюд.

## Как открыть

Дважды щёлкните `index.html` — сайт откроется в браузере. Локальный сервер не нужен.

Для шрифтов (Google Fonts) и фото плова нужен интернет. Без интернета сайт всё равно работает: будут стандартные шрифты и узорные тарелки с буквами вместо фото.

Чтобы показать сайт с телефона, проще всего выложить папку на GitHub Pages.

## Что заменить на настоящие данные

Всё меню — в начале `script.js`, массив `MENU`.

**Цены.** Сейчас у всех блюд `price: null` — на сайте «Цена уточняется». Впишите число в рублях:

```js
{ id: 'plov', name: 'Плов из говядины', category: 'hot', price: 450, ... }
```

Итог в корзине посчитается сам. Пока цен нет, корзина пишет «Уточняется».

**Фото.** Положите файл в `images/` и укажите путь:

```js
photo: 'images/plov.jpg'
```

Фото обрезается кругом (как блюдо на тарелке), поэтому снимайте блюдо сверху и по центру, лучше квадратом от 800×800 px. Если фото не загрузится, автоматически покажется узорная тарелка с буквой.

Фото на первом экране меняется в `index.html`: найдите `Uzbek_palov_in_Yerevan_Food_Court` и замените ссылку в `src` на `images/ваше-фото.jpg`.

**Описание блюда.** Поле `description`. Заполняйте только проверенным составом — пустое поле на сайте не выводится.

**Крупные карточки.** `featured: true` делает карточку широкой на компьютере.

**Телефон и часы работы.** В `index.html` найдите строку «Телефон и часы работы появятся здесь» и замените её настоящими данными.

## Корзина и заказ

- Добавление блюда не открывает корзину — появляется короткое уведомление с кнопкой «Открыть корзину».
- В корзине можно менять количество и удалять блюда.
- «Оформить заказ» открывает форму (имя, способ получения, комментарий). Можно вернуться в корзину — блюда сохраняются.
- Подтверждение показывает, что это демо: **заказ никуда не отправляется**, данные никуда не передаются.
- Корзина хранится только пока открыта страница; после перезагрузки она пустая.
